# 0.4.4 助手功能接入

日期：2026-10-10。本次接通目标架构的首批运行路径。

## 使用

设置 → 助手有三个入口：

- 身份：编辑助手的身份与交流风格，可恢复内置默认，旧 ANSWER 提示词可复制为草稿。私人内容留在加密 DataStore，普通配置导出不包含身份。
- 技能：周回顾、项目梳理、行动规划随 APK 内置；开关保存后保留至升级。对话输入 `/weekly-review`、`/project-review`、`/personal-planning` 明确选用。关闭不会删除记忆。
- 记忆方式：配置独立记忆提取模型后，可开启「自动整理候选」。回答完成后自动整理该条用户消息，所有变更仍需审核；默认关闭。可以主动检查助手模型的真实工具能力，检查只发送固定合成测试文字，会产生少量模型费用。

未通过工具探测的模型仍能普通聊天，并使用固定记忆上下文和明确选中的技能；不会解析普通回复里的伪工具 JSON，也不会更换 provider。通过后可按需查询记忆、来源与加载技能。

## 运行与持久化

每轮固定身份／运行约定正文和版本、启用技能版本／哈希。新启用的技能和身份编辑下一轮生效；关闭已使用技能会取消本轮。关闭与最终结果提交共用授权锁，避免关闭后迟到结果发布。禁用或不存在的显式技能在联网前拒绝，并提示到技能页检查。APK 清单在构建阶段校验全部资源哈希、YAML、重复 ID、引用与循环；运行时渐进读取并检查包内路径、长度及权限。

原生工具只读：`get_personal_profile`、`search_memories`、`get_memory_sources`、`search_local_sources`、`load_skill`、`read_skill_resource`。来源查询限于有效已确认记忆关联的保留证据，不扫描无关聊天或录音全文，不提供写入／删除／发送／脚本工具。每个回执先同事务追加 `AgentToolCallCompleted`、保存可删除正文和新依赖快照，再返回模型；重复调用 ID 复用回执，参数不同则拒绝。忘记会清理历史上下文、回执与回复，迟到结果不能提交。聊天按实际记忆版本、来源和历史消息依赖校验，无关的新候选不会打断回答；Memory Planner 仍使用原有全局知识修订保护。

聊天由进程协程持有，全局最多两轮并发，每轮最多 3 次工具交互、6 次新调用、2 个技能、120 秒；每份工具结果约 1,800 字符，累计结果 12,000 字符。技能元数据预算 1,500 字符，实际工具请求另设 24,000 字符保守上限，不截断半份技能规则；自定义身份和技能组合超过 8,000 字符会提示缩短。此版本没有模型特定 token 计数器和可编辑预算。

自动整理仍复用独立 MEMORY 的业务任务事件，自动来源进入可删除输入快照，同一消息跨失败／取消也不会自动重试。每次最多接纳四个新来源，逐项串行执行；超额留给用户手动整理。关闭仅取消自动任务，手动任务保留；提交前再次检查授权、来源及知识版本。应用重启将未完成任务标为中断，不重新上传历史消息。投影重建只读取事件与保留正文，不调用模型、加载新技能或触发自动整理。

## 当前边界

自动学习在本轮意味着自动提出候选，尚不直接确认普通事实。WorkManager 历史批次整理、可删会话摘要、近期变更专页、任意主题语义删除和真实模型质量评估尚未交付。未使用真实密钥或个人录音验证模型质量；HTTPS 假服务测试只证明格式、取消和持久化边界。
