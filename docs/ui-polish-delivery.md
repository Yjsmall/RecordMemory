# 界面打磨 · 0.2.1

日期：2026-10-09。

此次重做录音首页、列表、播放详情和设置页的视觉层级。使用暖白背景、墨绿主操作、统一线性图标和圆角分组；深色模式使用独立的中性表面色。调整标题、正文、辅助文字的字阶与间距，修正未指定语义色造成的紫色边框。

- 首页去除口号与底部技术说明，以计时和开始按钮为中心；录音按日期分组，正常保存的列表项只显示时长和格式。宽屏选中项有高亮。
- 播放页将音频标识、时长、进度和播放操作放在一个卡片中；移除重复的存储、编码与开发计划说明。
- 设置使用服务、模型、外观和迁移四个分组；移除重复的“编辑／配置”尾部文字。多服务与独立模型绑定继续可用。
- 服务编辑默认显示预设、名称、地址和密钥；协议、鉴权开关、转写开关和请求路径收进高级设置。豆包必要的语音凭据仍直接显示。
- 推荐模型收进模型输入框的下拉入口，避免“模型名”与“推荐模型”重复占用空间；支持直接填写自定义模型。提示词保留可编辑正文，删去字段下的长篇解释。
- 保留影响实际判断的提示：AI 功能待接入、豆包只检查格式、密钥留空保留、删除与放弃确认、文本测试调用与费用说明。

未改变录音服务、业务事件、存储协议或网络适配器。录音格式仍为 M4A，AI 业务任务仍待接通。
