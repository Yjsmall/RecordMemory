# vivo 原子通知：官方接入核对与 0.3.2 交付

目标设备由用户提供：vivo X Fold 6 / OriginOS 7。当前仅连接 Android 模拟器，没有 vivo 真机，因此不将本次修改描述为“胶囊已修复”。

## 找到的官方限制

2026-10-10 从 vivo 开放平台公开文档目录与正文接口核对以下文档：

- [原子通知接入指导](https://dev.vivo.com.cn/documentCenter/doc/894)：应用先在 vivo 应用商店上架；申请准入，等待团队审核；需求与设计评审后由 vivo 开通权限，再联调上线。准入审核标注 7–10 个工作日，功能按机型逐步放量。
- [原子通知规范](https://dev.vivo.com.cn/documentCenter/doc/895)：原子通知对应的落地页在前台时，状态栏普通胶囊／原子岛胶囊临时隐藏，退出页面后恢复。
- [原子通知技术规范](https://dev.vivo.com.cn/documentCenter/doc/896)：本地创建、更新和取消不需要云端 VPush 接入；`getSceneStatus(pkgName, sceneName)` 是可反射调用的只读场景开关查询，不是申请准入的接口。

尚无证据表明当前 `dev.local.record` 包已经取得 vivo 原子通知准入。通知总开关、前台服务正常、`notify()` 返回、通知在系统队列中，均不能证明胶囊已获准显示。场景查询返回 false 也不能单独区分“用户关了开关”和“场景尚未准入”；查询方法不存在／受限时不能猜测权限状态。

上版参考的 OriginOS 6 社区项目使用导航场景并要求替代其他应用包，不能作为本应用在 OriginOS 7 获准显示的依据。本次改用官方文档，不引入社区库，不复制它的实现。

## 应用侧调整

- 删除 `setSuperXInfosSceneList` 自行注册调用，仅查询官方说明的 `getSceneStatus`；异常类型可见，不吞掉集成失败。
- 使用官方基础模板 4，停止保存通过基础区胶囊动作执行；普通麦克风前台服务通知仍提供暂停／继续和停止保存。
- 本地首次创建 operation=0，之后更新 operation=1，递增 `changedRecord`；只有发送返回后推进 revision，避免首次发送抛异常后误发更新。
- 按官方本地样例使用固定的无 tag 通知 ID 101 创建／更新；取消时调用官方 `VIVO_SUPERX_TAG` 取消路径，并清理无 tag 记录和旧版卡片。
- 明确请求通知／锁屏／状态栏触点 `displays=0x111`；同时提供 island 和 capsule 内容。无限时显示采用文档默认值，不猜测 `showTime`。
- 胶囊明确白字、墨绿底；原子通知使用独立的墨绿底白色麦克风资源，兼顾黑色岛与浅色通知卡。补齐右岛点击动作。
- 删除未获官方文档证实的模板 8、强制显示等字段。录音候选场景仍是 `TIMER`，**这只是已有接入的候选值，官方公开列表没有承诺录音／TIMER 准入，必须由 vivo 确认最终场景**。
- 设置 → 录音 → 录音通知提供刷新、系统通知设置、复制报告。报告只含设备型号、Android／系统版本、应用版本、开关、渠道、场景查询、发送／取消结果和本应用通知 ID 是否存在；不含音频、标题、正文、API Key、通知内容或设备唯一标识，不自动上传。

不启动麦克风来生成诊断，不修改系统场景权限，不借用其他应用包，不引入隐藏 API 绕过库。录音数据库与业务事件没有迁移。

## 待 vivo 确认的接入材料草稿

- 应用：随声记。
- 包名：`dev.local.record`。
- 服务场景：用户主动开启本地录音，返回桌面后持续显示录音计时；暂停时显示暂停状态；停止保存后移除通知。
- 交互：胶囊展示计时与麦克风，点击进入录音页／卡片；卡片提供停止保存；普通前台服务通知提供暂停／继续与停止。
- 数据：仅本地录音，无远程推送需求；不将个人音频交给通知平台。
- 需要平台明确：录音是否允许接入、最终 scene、X Fold 6 / OriginOS 7 内外屏显示规则、测试包／签名的准入方式。
- 上架状态、发布签名、开发者联系资料待正式申请时补充；当前为本机 debug 签名。本文不是已通过的准入或申请，不会代用户发送邮件。

## 真机验证

1. 覆盖安装 0.3.2，不卸载或清除数据。开始录音，确认普通通知存在且计时增长。
2. 返回桌面等待约 10 秒；检查胶囊，随后展开／合拢，在内外屏分别检查。进入应用落地页后胶囊隐藏符合官方规则。
3. 保持录音，打开设置 → 录音通知 → 复制报告，把报告用于排查。报告不含录音或密钥。
4. 检查系统对随声记的通知／原子通知开关（入口由 ROM 决定）。没有本应用场景入口时，不把打开普通通知权限当作原子通知准入。
5. 普通通知暂停／继续与停止保存应可用；保存后通知退出，录音可播放。

如果官方准入未开通，应用侧代码不能保证胶囊出现；后续应先确认场景准入，不能仅通过继续变换 Bundle 参数来宣布成功。
