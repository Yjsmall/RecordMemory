# 私人助手功能接入实施计划

**Goal:** 接通身份编辑、APK 内置技能、真实工具主动回忆和可选自动候选整理。

**Spec:** `docs/architecture/personal-agent.md`。本轮按已有目标架构实施；自动学习先采用自动整理、人工审核，暂不自动确认模型推断。

**Architecture:** 复用加密 DataStore 保存私人身份、技能开关和自动整理授权，快照进入可删除的 AssistantContext。工具仅开放本地只读能力，Responses / Chat 原生工具协议经过主动探测才启用。独立 MEMORY 整理使用已有事件任务作为持久化执行意图，进程中断不自动重试付费请求。

**Global constraints:** 原生 Kotlin / Compose；固定工具链；jj colocated；业务事件和投影同事务；重放不联网、不加载新技能、不调度；密钥及私人内容不进入仓库；不使用 Embedding；禁用技能和忘记在上传与提交前重新校验。

- [x] 配置与资源：内置身份、运行约定、周回顾／项目梳理／行动规划；严格 YAML／清单／哈希／路径与预算校验；技能开关和编辑持久化；设置中三个助手入口。验证重复 ID、越界、禁用、快照、重启保存。
- [x] 工具协议：统一 ToolCall / ToolResult；两种协议的请求／返回格式；主动能力探测；有限只读循环。验证 ID 对齐、参数 JSON、重复调用和预算。
- [x] 自动整理：默认关闭；独立 MEMORY 配置；回答成功后形成唯一任务，自动执行候选整理；关闭取消在途整理；来源／忘记与中断保护。验证重复、关闭、来源失效和重放。
- [x] 运行时接线：身份及技能配置快照、显式技能选择、只读工具分派、检索依赖和回执进入可删除上下文；最多3轮／6调用／120秒。确认同会话串行、进程所有权、禁用与迟到响应保护。
- [x] 验证与交付：单元、仪器测试（有设备时）、assembleDebug、lintDebug、ktlint、detekt；记录真实结果及未覆盖项，更新架构当前状态。

执行采用独立文件范围的并行任务，统一构建和接线在主会话完成。
