# 现有功能界面打磨

日期：2026-10-10。基于 `design-ui` 的任务连续性、按任务分配复杂度和真实状态反馈原则，在现有暖白／墨绿 Material 3 Expressive 主题上调整页面。版本号仍为 0.4.5。

## 改变与取舍

- 首页将私人助手和检索与学习统一成带图标、说明和整行热区的入口。空间足够时并排，窄窗或大字体时纵向排列；计时字号略收敛，录音操作仍是主要视觉区域。
- 检索先展示关键词，日期与项目按需展开。收起不清空条件，有已填条件时显示数量。窄区域或大字体使用纵向日期字段；键盘搜索动作也能提交本机检索。
- 选中聊天后，整理按钮固定在页面底部。查找与上传整理保持独立，点击整理后仍需确认服务、调用次数与费用。选中热区包含复选框与文字，读屏能识别选中和展开状态。
- 最近学习将变更类型、审核状态、时间和正文分开排版；来源、依据和模型可展开查看，失败提示保持直接可见。待审核替代使用“建议改为”，已保存变更才使用“现在”。
- 助手空白页提供明确的草稿入口；功能检查提示放到空白页，减少对正文的持续占用。未配置记忆模型时不再在每条回答下重复配置入口，仍可从对话菜单配置。候选操作可换行，输入框保持在消息滚动区域外。
- 记忆库优先呈现待审核内容，区分审核状态与变更类型。已确认但未到生效日期／已过期的事实保留“当前未生效”提示。忘记范围入口使用用户可理解的名称，解除仍需明确确认。
- 技能卡片明确提供用法与详情入口，选中高亮；记忆方式按如何整理、如何保存和主动回忆分组。设置摘要同时反映自动整理和自动保存选项。

## 实际尺寸问题

截图发现：在宽折叠窗口内承载窄内容区域时，原双栏决策只读取 Activity 窗口，录音区域被挤窄。新增断言复现窄区域仍出现详情占位。修正为窗口／折叠指令与内容实际约束共同决定单双栏，且考虑字体比例；只收紧分栏数，保留折叠遮挡信息及原 Navigation 3 栈。

业务服务、事件、数据库和网络适配器没有修改。界面重建继续复用原服务和 ViewModel。
