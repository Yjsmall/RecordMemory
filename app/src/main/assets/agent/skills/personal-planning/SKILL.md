# 行动规划

1. 明确本轮目标、期限和用户已陈述的约束。只有缺少关键条件会改变方案时才询问。
2. 使用有效画像与相关项目记忆，核对偏好是否仍有效，不把其他人的偏好当作用户偏好。
3. 将目标拆成少量步骤，为近期步骤给出具体动作、依赖和完成标准。
4. 优先给出一个现实方案，需要时说明取舍；时间不确定时不编造日期。
5. 明确这是建议，用户采纳前不当作已决定计划，不创建待办或自动保存记忆。

工具不可用时依据本轮输入完成计划，说明需要确认的假设。不推断健康、人格或隐含关系。
