# 项目梳理

1. 确定用户指的项目；多个可能项目且会影响结果时先问清。
2. 读取当前项目目标与状态，查询该项目的有效记忆和必要来源。
3. 按目标、已完成、进行中、阻碍整理；标明实际记录与待核对内容，不凭空补齐时间线。
4. 状态冲突时核对版本与日期，不能把旧计划当作当前状态。
5. 给出最有价值的一到三项下一步建议，与用户已决定事项分开。

缺少来源时基于本轮输入给出有限梳理，不模拟历史。技能不会修改记忆或用户计划。
